# TaxyCity - Мобильное приложение для заказа такси

Приложение для заказа такси, разработанное на Flutter. Позволяет клиентам заказывать такси, а водителям - принимать заказы и управлять ими.

## Возможности

### Для клиентов:
- Регистрация и авторизация
- Заказ такси с выбором тарифа (Эконом, Комфорт, Бизнес)
- Указание адреса отправления и назначения
- Заказ такси на определенное время
- Отслеживание статуса заказа
- Внутренний чат с водителем
- Звонок водителю
- Отмена заказа
- Предварительный расчет стоимости

### Для водителей:
- Регистрация с указанием номера автомобиля, марки и цвета
- Просмотр доступных заказов
- Принятие и отклонение заказов
- Изменение статуса заказа (в пути к клиенту, у клиента, в пути, завершен)
- Внутренний чат с клиентом
- Звонок клиенту
- Личный кабинет с информацией об автомобиле и заработке

## Технологии

- **Flutter** - кроссплатформенный фреймворк для разработки мобильных приложений
- **Dart** - язык программирования

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/ctonew/taxycity.git

# Переход в директорию проекта
cd taxycity

# Установка зависимостей
flutter pub get

# Запуск приложения
flutter run
```

## Структура проекта

```
lib/
├── main.dart                    # Точка входа в приложение
├── screens/
│   ├── welcome_screen.dart      # Экран приветствия
│   ├── login_screen.dart        # Экран входа
│   ├── driver_registration_screen.dart   # Регистрация водителя
│   ├── client_registration_screen.dart   # Регистрация клиента
│   ├── driver_home_screen.dart  # Главный экран водителя
│   ├── client_home_screen.dart  # Главный экран клиента
│   ├── client_order_screen.dart # Экран отслеживания заказа
│   └── chat_screen.dart         # Чат между водителем и клиентом
```

## Скриншоты

Приложение включает:
- Экран приветствия с выбором типа пользователя
- Формы регистрации для водителей и клиентов
- Личные кабинеты с соответствующим функционалом
- Интерфейс для заказа такси
- Систему отслеживания заказа в реальном времени
- Встроенный чат
